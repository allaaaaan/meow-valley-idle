# 喵喵谷

一座会慢慢长大的山谷小镇。竖屏就能玩。所有美术都用代码画成，没有用 AI 出图。

## 现在就玩

👉 **[打开喵喵谷](https://allaaaaan.github.io/meow-valley-idle/)**

## 放到 iPhone 主屏幕

1. 用 **Safari** 打开上面的链接（只有 Safari 能加到主屏幕）。
2. 点底部分享按钮（方框加向上的箭头）。
3. 滑到「添加到主屏幕」，再点「添加」。
4. 主屏幕上会出现「喵喵谷」，点开后会全屏运行，像一个独立应用。

说明：Safari 里的存档，和主屏幕应用里的存档是分开的。第一次从主屏幕打开，会是一座新的小镇。

离线时，主屏幕应用会继续用上次缓存的版本；重新在线打开一次就会更新。

## 本地打开

直接打开 `index.html`。地址栏加上 `?fresh` 会重置存档。
